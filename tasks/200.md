# タスク: Build Craft Neo(自作 MOD 本体)の実装

あなたは Minecraft MOD パックプロジェクト "Civilization Frontier: Beyond the Cataclysm" の作業エージェントです. 自作産業 MOD の Build Craft Neo を実装します. このパックの中核となる最後の大タスクです.

## 前提知識

* ワークスペース: `/ws`、Minecraft `26.3` + Fabric. 実装言語は Java、Fabric Mod として開発
* 設計の原文は `/ws/README.md` の「2. 工業」. `MJ` エネルギー、エンジン、パイプ、露天掘り機、制御回路が要件
* 関連追加要件:
  * 重火器: `26.3` 対応の既存 MOD が無いため自作. 大砲・攻城兵器など低負荷設計の発射物エンティティ
  * 農業自動化: 対応 MOD が無いため自作. 作物の自動栽培・収穫設備
  * 鉄道高度化: Improvement Minecarts(連結列車・機関車・駅)は導入済み. 時刻表ダイヤ・信号システムは自作
* 連携要件:
  * 重工業稼働や兵器使用は EFP(Pollution of the Realms)へ汚染加算する連携が前提
  * 工業中間素材は MD 通貨の納品対象になる設計
* 先行タスクで導入済みの周辺: エネルギー伝送・パイプ輸送・自動採掘・精錬は BCN の責任範囲

## タスク詳細

1. エネルギー基盤 `MJ`
   * Minecraft Joules の生成・伝送・消費の基礎実装
2. エンジン
   * 燃料消費による MJ 自動生成装置(RS 信号駆動の簡易型から核エネルギーまで段階的に)
3. パイプ
   * アイテム輸送ネットワークと倉庫システム
4. 露天掘り機
   * 地上から岩盤までの全自動採掘
5. 制御回路
   * 壁面配線可能な RS ワイヤー、小型論理回路素子によるオンデマンド制御
6. 重火器
   * 低負荷設計の大砲・攻城兵器. Spell Engine の投射物機構を流用できる可能性がある
7. 農業自動化
   * 作物の自動栽培・収穫設備
8. 鉄道高度化
   * Improvement Minecarts 上位の時刻表ダイヤ・信号システムによる自律運行

## 制約・注意点

* `26.3` + Fabric で動作すること. 既存 MOD とのアイテム・ブロック ID 衝突に注意
* 重火器は「負荷の少ないもの」が要件. エンティティ数・tick 処理を抑える設計にする
* EFP 連携口(稼働・使用時の汚染加算)は API として露出させる

## 完了条件

* MJ による機械稼働から露天掘りまでの産業ループが成立する
* 重火器・農業自動化が実装され、EFP 連携口が利用可能になる
