# タスク: 経済・環境システムの実装

あなたは Minecraft MOD パックプロジェクト "Civilization Frontier: Beyond the Cataclysm" の作業エージェントです. MD 通貨、土地維持費、EFP 連携、災害イベント、クエストエンジンを実装します.

## 前提知識

* ワークスペース: `/ws`、Minecraft `26.3` + Fabric
* 設計の原文は `/ws/README.md` の「3. 経済」「4. 環境負荷指数」「5. 災害」
* 導入 MOD(抜粋):
  * Coins JE: `MD` 硬貨の基盤 MOD
  * Universal Shops `1.16.0`: プレイヤー間交易店
  * Flan `1.12.8.b`: サーバーサイドのチャンククレーム(土地保護)
  * Pollution of the Realms (AdPother) `26.3.0.1`: 環境汚染の蓄積と世界への影響
  * Undead Nights `2.2.6`: 周期夜のアンデッド軍団襲撃イベント
  * JustQuests `0.4.2` / Daily Quests `4.0`: 軽量クエスト系(本格クエスト本の代替)
* 設計要件:
  * `MD` = Minecraft Dollar. 銅・鉄・金・エメラルド・ダイヤモンド・ネザライト規格の硬貨
  * 獲得経路: クエスト達成、ダンジョンボス討伐、工業中間素材の納品
  * `EFP` = Environmental Foot Print. 重工業稼働・兵器使用で蓄積する汚染指数. 閾値超過で災害発生
  * 災害は 3 種: "黄昏"(世界が黄昏化)、"脅威"(強モンスター増加)、"襲撃"(拠点への大襲撃)
  * クエスト: 「やるべきことを記述 → 達成判定 → 報酬」、報酬は MD・スキルポイントと連携

## タスク詳細

1. MD 通貨設計
   * 硬貨階級の定義と、獲得・消費・商店利用の循環を実装する
   * Coins JE と Universal Shops を連携させる
2. 土地維持費
   * Flan のクレームに対する MD 定期徴収ロジックを自作する
   * 未納時のペナルティ(クレーム解除・機能停止等)を設計する
3. EFP 連携
   * Pollution of the Realms への重工業稼働・兵器使用による汚染加算を連携する
   * 閾値の監視と超過時のイベント発火口を実装する
4. 災害イベント
   * "黄昏" の演出・環境変化、"脅威" のスポーン増加を自作実装する
   * "襲撃" は Undead Nights の夜襲と連動させる
5. クエストエンジン
   * 章立てガイド型クエスト(記述→判定→報酬)を実装する
   * JustQuests/Daily Quests で不足する分は自作し、スキルポイント授与と連携する

## 制約・注意点

* 既存 MOD の機能を最大限活用し、自作は連携・不足部分に絞る
* EFP→災害の因果関係は設計の中核なので、閾値と発火の整合を明確にする

## 完了条件

* MD の獲得・消費・商店利用が一巡して動作する
* 領地維持費が定期徴収される
* EFP が閾値超過で災害を起こし、"襲撃" が Undead Nights と連動する
* クエストの受注から報酬受領までが動作する
