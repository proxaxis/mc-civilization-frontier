# タスク: BCN silicon(laser/assembly/chipset/gate/robot)

あなたは Minecraft MOD パックプロジェクト "Civilization Frontier: Beyond the Cataclysm" の作業エージェントです. BCN のシリコン系(精密作業・チップ・BC式ゲート・ロボット)を実装します.

## 前提知識

* ワークスペース: `/ws`、Minecraft `26.3` + Fabric、Java、Fabric Mod
* BCN プロジェクト: `/ws/app` (Fabric Loom, JDK25)
  * ビルド: `JAVA_HOME=/opt/jdk25 /opt/gradle-9.8.0/bin/gradle build`
* 仕様: `/ws/docs/TECH_ITEMS.md` BuildCraft 節 6-7
* 検証: testserver, RCON 25575/devpassword
* Markdown 記述ルール: `/ws/AGENTS.md`

## 既存の基盤

* MJ 基盤, Assembly Table 系は MJ 消費型独自クラフト UI(ケーブル直結)の方針確定済み
* redwire + logic gate(206)の基盤 — BC 式ゲートは別系統として併存可

## タスク詳細

1. `assembly_table`(精密作業台) — MJ 消費でレーザーを受けて長時間クラフト. 内部レシピをデータ駆動(JSON)化
2. `laser`(レーザー) — MJ 消費で近くの assembly_table にエネルギーを照射. ビーム描画は BlockEntityRenderer
3. チップセット 8 種 — `chipset_redstone/iron/gold/quartz/diamond/pulsating/comp/emerald`. assembly_table レシピで製造、ゲート・改造の素材
4. BC 式ゲート — `gate_iron/gold/diamond/emerald/quartz` の AND/OR. redwire とは別系統の「条件→アクション」ロジック(パイプに接続して搬送制御). 今回は簡易: redstone 条件でパイプ抽出を制御
5. ゲート改造 — clock timer, redstone fader, autarchic pulsar, light sensor(コンポーネントとして保存可能なアイテム)
6. `integration_table`/`charging_table`/`gate_copier`/`advanced_crafting_table` — 派生作業台
7. `robot`/`docking_station`/`redstone_board`/`redstone_crystal` — ロボット系(スコープ最小: アイテム登録+簡易 dock 動作)

優先: assembly_table + laser → chipset → 簡易 BC gate → 残り

## 完了条件

* assembly_table + laser でチップが製造できる
* BC 式ゲートが redstone 条件でパイプ抽出を制御できる
* ロボットは登録+最小限の dock 動作で可(完全自動化は別タスク)
