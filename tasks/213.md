# タスク: BCN builder 系(landmark/filler/blueprint/architect/builder)

あなたは Minecraft MOD パックプロジェクト "Civilization Frontier: Beyond the Cataclysm" の作業エージェントです. BCN の建築支援機器(builder 系)を実装します.

## 前提知識

* ワークスペース: `/ws`、Minecraft `26.3` + Fabric、Java、Fabric Mod
* BCN プロジェクト: `/ws/app` (Fabric Loom, JDK25)
  * ビルド: `JAVA_HOME=/opt/jdk25 /opt/gradle-9.8.0/bin/gradle build`
* 仕様: `/ws/docs/TECH_ITEMS.md` BuildCraft 節 5 (旧builder)
* 検証: testserver, RCON 25575/devpassword
* Markdown 記述ルール: `/ws/AGENTS.md`

## 既存の基盤

* MJ 基盤, FakePlayer 採掘, レーザー不要のシンプル設計方針
* quarry のチャンクロード制約(常駐ロード無し)の設計を踏襲

## タスク詳細

1. `landmark`(青マーカー) — 設置で直交する赤線を表示し範囲指定の基準点に. 3 個で直方体範囲を決める
2. `filler`(フィラー) — landmark で決めた範囲にインベントリ内ブロックを充填/削平/階段等のパターン配置(MJ 消費)
3. `template`/`blueprint` — スナップショットを保存するアイテム. template は素材、blueprint は完全保存
4. `architect_table`(製図机) — landmark 範囲を blueprint/template に書き込む UI
5. `builder`(ビルダー) — blueprint を読み込みインベントリ素材で実物を組み立て(MJ 消費)
6. `path_mark`(緑マーカー) — パス指定用
7. `map_location`/`list` — 範囲指定・リストのアイテム基盤

優先: landmark → filler → template/blueprint → architect_table → builder

## 完了条件

* landmark 3 点で範囲が決まり filler が充填動作する
* blueprint が範囲を保存・builder が再現できる
* MJ 消費で動作しロード済みチャンクのみ稼働する
