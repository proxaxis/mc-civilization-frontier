# タスク: BCN IC2 加工機(macerator/extractor/compressor/canner/alloy smelter)

あなたは Minecraft MOD パックプロジェクト "Civilization Frontier: Beyond the Cataclysm" の作業エージェントです. BCN の IC2 系加工機を実装します.

## 前提知識

* ワークスペース: `/ws`、Minecraft `26.3` + Fabric、Java、Fabric Mod
* BCN プロジェクト: `/ws/app` (Fabric Loom, JDK25)
  * ビルド: `JAVA_HOME=/opt/jdk25 /opt/gradle-9.8.0/bin/gradle build`
* 仕様: `/ws/docs/TECH_ITEMS.md` IC2 節 + 実装方針の「処理レシピはデータ駆動化」
* 検証: testserver, RCON 25575/devpassword
* Markdown 記述ルール: `/ws/AGENTS.md`

## 既存の基盤

* MJ 消費機のパターン(quarry/refinery 実績), 立方体+前面インジケータ+active モデル
* `recipes_export.json`/`machine_recipes_export.json` を基にしたレシピデータ駆動方針は確定済み

## タスク詳細

1. `macerator`(粉砕機) — 鉱石→粉末 2 倍化、インゴット→粉末
2. `extractor`(抽出機) — ゴム樹液→ゴム, 一部素材の高効率抽出
3. `compressor`(圧縮機) — 石炭塊→ダイヤ, 合金素材等の圧縮
4. `canner`(缶詰機) — セル/バケツへの流体充填(燃料缶・核燃料等)
5. `alloy_smelter`(合金炉) — 複数素材を 1 つに合金化(青铜等)
6. 共通機械フレームワーク — 加工機共通の BlockEntity(入力スロット+進行度+出力スロット+MJ 消費+レシピ解決). レシピは JSON データ駆動で機械種ごとに分離
7. 加工レシピ JSON — `machine_recipes_export.json` から主要レシピを移植

## 完了条件

* 5 機械が MJ 消費で加工動作する
* レシピが JSON から読まれ、追加がデータ駆動でできる
* 加工中は前面 active 表示が切り替わる
