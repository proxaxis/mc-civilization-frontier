# タスク: 職業ガイドドキュメント(JOB_*.md)の作成

あなたは Minecraft MOD パックプロジェクト "Civilization Frontier: Beyond the Cataclysm" の作業エージェントです. 4 職業のプレイヤー向け詳細ガイドを作成します.

## 前提知識

* ワークスペース: `/ws`、ドキュメントは `/ws/docs/` 以下
* 世界観と職業概要は `/ws/README.md` と `/ws/docs/GUIDE.md` に記述済み
* 4 職業は `守護者`、`暗殺者`、`魔道士`、`聖職者`. 役割の概要は README の「1. 職業」に記述済み
* テンプレートは `/ws/docs/JOB_GUIDE_TEMPLATE.md`. 構成は「特徴 → パッシブスキル → アクティブスキル → 装備品」
* 対象ファイル `JOB_GUARDIAN.md`、`JOB_ASSASSIN.md`、`JOB_MAGE.md`、`JOB_PALADIN.md` は空または未作成
* 導入 MOD と職業の対応:
  * 守護者: Paladins & Priests(パラディン系術式・盾・メイス)
  * 暗殺者: Rogues & Warriors(ローグ系・短剣・クナイ・煙幕・ステルス)
  * 魔道士: Wizards(火炎・凍結・雷撃の属性術式・杖・ローブ)
  * 聖職者: Paladins & Priests(プリースト系・回復・加護)
  * 伝説武器は Arsenal(攻略限定の固有武器)
* パッシブスキルは Pufferfish's Skills による経験値強化型ツリー、アクティブスキルは満腹度消費 + クールダウン + 消費アイテム(巻物等)の設計
* 世界観の補足: スキル発動は満腹度(疲疲労度・隠し満腹度)を激しく消費する設定. 食料兵站が攻略の鍵

## 記述ルール(必須)

* `/ws/AGENTS.md` の Markdown 記述ルールに従うこと
  * 太字 `**` は使わない
  * 中黒 `・` は `、` や `または` で代用
  * 句点 `。` は使わず `. ` を使う
  * 鉤括弧 `「」` は使わず `""` を使う
  * 閉じ括弧 `）` の後に `.` は付けない

## タスク詳細

1. `JOB_GUIDE_TEMPLATE.md` の構成に準拠して 4 ファイルを作成する
2. 各職業で、役割・特徴、パッシブスキル(経験値強化・満腹度消費なし)、アクティブスキル(満腹度消費・クールダウン・消費アイテム)、装備品を記述する
3. スキルと装備の性能値・名称は、別タスク(103 での実装)と整合させるため、未確定箇所は "仮" と明記してよい
4. 対応 MOD の実在要素(術式名、武器種、アーマー種)をできるだけ反映させる. 不明な場合は RPG Series の wiki / 既存ドキュメントの用語に揃える
