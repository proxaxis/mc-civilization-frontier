# タスク: BCN 油田コンテンツ仕上げ (流体描画・挙動検証・調整)

あなたは Minecraft MOD パックプロジェクト "Civilization Frontier: Beyond the Cataclysm" の作業エージェントです. 先行実装した BCN のワールド生成コンテンツ(鉱石・油田)について、クライアント描画の未実装修正と挙動検証、バランス調整を行います.

## 前提知識

* ワークスペース: `/ws`、Minecraft `26.3` + Fabric、実装言語は Java の Fabric Mod
* BCN プロジェクト: `/ws/app` (Fabric Loom, JDK25, ビルドは `JAVA_HOME=/opt/jdk25 /opt/gradle-9.8.0/bin/gradle build`)
* 成果物: `/ws/app/build/libs/bcn-0.1.0.jar` → `/ws/resources/mods/` へ配置
* 検証環境: docker compose の `testserver` (コンテナ `mc_civilization_frontier_testserver`, RCON 25575/devpassword) とローカル Fabric サーバ. クライアント描画の検証にはクライアント起動または jar 内リソース確認が必要
* 実装済み: 鉱石 17 種 + deepslate, 大理石, オイル流体/バケツ/油源泉ブロック, worldgen JSON, loot_table, ITEMS.md 公式レシピ併記 (詳細は REPORTS.md と /ws/docs/TECH_ITEMS.md)

## 現状の既知不具合

* 黒オイルが missing テクスチャ表示になる
  * 原因: `fabric.mod.json` に `"client"` エントリポイントが無く、`FluidRenderHandlerRegistry` による流体レンダラ未登録. `oil_still.png` (16x512 アニメ), `oil_flow.png` は存在する
  * 想定修正: `BcnClient` (ClientModInitializer) を新設し `SimpleFluidRenderHandler` で `BcnFluids.OIL`/`FLOWING_OIL` に `bcn:block/oil_still`, `bcn:block/oil_flow` を登録、`fabric.mod.json` に `"client"` を追加

## タスク詳細

1. 流体レンダラ実装 (上記既知不具合の修正)
   * クライアント側でオイル液体が黒テクスチャ+アニメーションで描画されることを確認
   * 併せてオイルバケツ/油源泉ブロックの描画も目視確認
2. 流体挙動の実機検証
   * 無限水源が作れないこと, 流れが浅いこと (BC 仕様: 3マス)
   * エンダーマン/ブレイズへのダメージ, 沈降力
   * 溶岩との接触で黒曜石生成
   * ネザー設置で爆発
   * 着火時の燃え移り (REPORTS 未検証項目)
3. 生成バランス調整
   * 油田レア度/サイズ (現状: 砂漠 1/200, 海洋 1/250, 池 1/80) を実プレイ目線で見直し

   * improvement_minecarts 同梱 predicate の 26.3 互換パッチを恒久対応 (resources 側の置き場所/管理方法を決める)
