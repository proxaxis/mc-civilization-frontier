# タスク: E2E 導線検証と実機確認

あなたは Minecraft MOD パックプロジェクト "Civilization Frontier: Beyond the Cataclysm" の作業エージェントです. 職業選択 → スキル解放 → 魔法習得 → ボス討伐の一連導線が実機で動作するかを検証し、不備を修正します.

## 前提知識

* ワークスペース: `/ws`、Minecraft `26.3` + Fabric
* 検証環境: `docker compose` の `testserver`(コンテナ名 `mc_civilization_frontier_testserver`)、`rcon-cli` でコマンド実行可能
* テストプレイヤー: `YSK357`(op 付与済み)
* 重要: `docker compose` 再作成時は `WORKSPACE_HOST_PATH=/home/me/devserver/mc-civilization-frontier` 必須
* 資産配置:
  * datapack(サーバーロジック): `/ws/resources/datapacks/{cfb_skills,cfb_economy,cfb_enemies}` → コンテナ内 `/data/world/datapacks/` へ docker cp 後 `reload`
  * bcn jar(クライアント共有): `/ws/app` で `JAVA_HOME=/opt/jdk25 /opt/gradle-9.8.0/bin/gradle build` → `build/libs/bcn-0.1.0.jar` → `/ws/resources/mods/` へ
  * クライアント側 jar も差替えが必要な変更あり(スペル定義等)

## 検証対象の導線(未検証事項)

### A. 職業選択 → スキルツリー

* メニュー(`trigger cfb_job`)で職業選択 → 対応カテゴリのみ unlock、他は lock される挙動
* [職業をリセットする] で `category erase` → 再選択できること
* Pufferfish 側でスキルポイント獲得・ノード解放が可能なこと

### B. スキル解放 → 魔法習得(最重要・未検証)

* アクティブ解放ノードを解放した時、`puffish_skills:command` reward が発火してスペル巻物が give されるか
* 付与された巻物を呪文結合台で呪文書へ結合できるか(spell_scroll タグ経由)
* 結合した cfb スペルがスロットキーで発動できるか
* 未習得スペルが spell_book から直接購入できないこと(購入封じ)

### C. クエスト → MD 流通

* `/function cfb:quest/menu` の申請 → 納品型(`clear` で消費)/討伐型(`minecraft.killed:` スコア)/探索型(advancement)が判定通るか
* 報酬の MD 硬貨・XP が正しく付与されるか
* `/function cfb:md/menu` の両替が動くか

### D. ボス・敵

* `/function cfb:boss/*` で 4 ボス召喚、tick ギミック(Fx)が動くか
* `/function cfb:spawn/set_*` の構造物セット出現が動くか

### E. 統合シナリオ(本来の完走テスト)

1. 職業選択 → ツリーでスキル解放 → 巻物入手 → 呪文書に結合 → スペル発動
2. クエストで MD 獲得 → 商店/両替で使う
3. スキル解放したキャラで構造物に向かい、敵と戦い、ボスを討伐する

## 既知の懸念(先に潰しておくべき箇所)

* `puffish_skills:command` reward の `command` が `@s` で実行されるか、また datapack 内の関数経由でないと権限エラーの可能性
* 巻物アイテムの NBT 構文が 26.3 で正しいか(`spell_engine:spell_scroll[...]` 形式は検証済みだが、reward 内のエスケープ次第)
* EFP 閾値・維持費は仮値のまま(実機バランス要調整)
* 構造物への自動出現トリガーは未配線(今回の検証では関数呼び出しで代替)
