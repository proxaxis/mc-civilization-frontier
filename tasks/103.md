# タスク: 魔法・スキル・職業システムの実装

あなたは Minecraft MOD パックプロジェクト "Civilization Frontier: Beyond the Cataclysm" の作業エージェントです. 職業ロック、スキルツリー、スペル実装を行います.

## 前提知識

* ワークスペース: `/ws`、Minecraft `26.3` + Fabric、サーバー・クライアント双方想定
* 導入 MOD(抜粋、全一覧は `/ws/docs/MOD_LIST.md`):
  * Pufferfish's Skills `0.19.2`: スキルツリー基盤. 経験値でノード解除し属性・能力を付与
  * Spell Engine `1.10.9`: データパック定義スペルの行使エンジン(クールダウン・当たり判定・演出)
  * Paladins & Priests / Wizards / Rogues & Warriors `3.1.4系`: 4 職業の術式・武具
  * Runes `1.3.2`: 術の弾薬アイテム(アイテム消費による術行使)
  * Arsenal `1.5.1`: 攻略限定の伝説武器. Ranged Weapon API `4.0.0`
* 4 職業と対応 MOD: 守護者=Paladins(パラディン)、暗殺者=Rogues、魔道士=Wizards、聖職者=Paladins(プリースト)
* 設計方針:
  * パッシブスキル = 経験値でスキルツリー解除し常時バフ(満腹度消費なし)
  * アクティブスキル = クラフト・探索で得たアイテムを使用して発動(満腹度消費 + クールダウン)
  * 術の行使に満腹度(空腹度・隠し満腹度)を消費する独自コストが必要
* 職業ガイド(`docs/JOB_*.md`、別タスク 102 で作成)の性能値と整合させる
* Pufferfish's Skills のドキュメント: https://puffish.net/skillsmod/docs/
* Spell Engine のデータパック定義は本体 wiki/docs を参照

## タスク詳細

1. 職業選択と排他ロック
   * ワールド参加時の職業選択 UI を実装する
   * 選択した職業のツリーだけ進行できるよう、Pufferfish's Skills のカテゴリ設計で排他制御する
2. スキルツリー定義
   * 4 職業分のノード・配線・パッシブバフ(属性付与)をデータパックで定義する
   * 経験値コストと効果量は JOB_*.md の記述と整合させる
3. アクティブスキル
   * Spell Engine のデータパックスペルを定義し、アイテム(巻物・武具)へ紐付ける
   * クラフト・探索での入手経路を設計する
4. 空腹度コスト
   * 術行使時に満腹度・隠し満腹度を消費するコスト処理を自作する
   * Spell Engine に無い機能のため、キャストイベントへのフックが必要
5. マナ・ルーン連携
   * Runes の弾薬消費と職業術式の整合を設定する

## 制約・注意点

* 実装はデータパック・コンフィグ優先、MOD 自体の改変は行わない
* 数値は JOB_*.md と照合し、矛盾があればドキュメント側を正として揃える

## 完了条件

* 職業選択後、対応ツリーだけが利用可能になる
* 経験値でのパッシブ強化と、アイテム経由のアクティブスキルが動作する
* 術の行使に空腹度が消費される
