# タスク: BCN LogisticsPipes(物流パイプ)

あなたは Minecraft MOD パックプロジェクト "Civilization Frontier: Beyond the Cataclysm" の作業エージェントです. BCN の LogisticsPipes 系(アイテム物流自動化)を実装します.

## 前提知識

* ワークスペース: `/ws`、Minecraft `26.3` + Fabric、Java、Fabric Mod
* BCN プロジェクト: `/ws/app` (Fabric Loom, JDK25)
  * ビルド: `JAVA_HOME=/opt/jdk25 /opt/gradle-9.8.0/bin/gradle build`
* 仕様: `/ws/docs/TECH_ITEMS.md` LogisticsPipes 節(基幹装置/モジュール/溶接台/リモートオーダー)
* 検証: testserver, RCON 25575/devpassword
* Markdown 記述ルール: `/ws/AGENTS.md`

## 既存の基盤

* item_pipe + BlockEntity 輸送の実績. LP はこの上に乗るアドオン構造の方針確定済み
* MJ 基盤で動力は MJ 直結(LP は MJ で動く)
* パイプの接続/終端・BlockEntity 搬送実績

## タスク詳細

1. 物流基幹パイプ — `pipe_basic_logistics`(基本物流パイプ). アイテムの要求→供給ルートを管理するネットワーク層
2. 供給系 — `pipe_provider`(プロバイダー): 接続したコンテナを供給源としてネットワークに登録
3. 要求系 — `pipe_request`(リクエスト): 条件を満たすアイテムをネットワークから引き込む
4. 補給系 — `pipe_supplier`(サプライヤー): 接続先に指定アイテムを補充し続ける
5. クラフティング系 — `pipe_crafting`: 自動作業台と接続して要求時にクラフト→搬送
6. 液体系 — `pipe_liquid_supplier`: 防水パイプ上の液体版サプライヤー
7. モジュール — `item_sink`(アイテムシンク), `extractor`(抽出), `polymorphic`(多型), `quick_sort` 等を管に挿すモジュールシステム
8. `soldering_station`(溶接作業台) — LP 部品を組み立てる作業台
9. `remote_orderer`(リモートオーダー) — 遠隔で要求を出せるアイテム

優先: basic → provider → request → supplier → module 系 → crafting → 残り

## 完了条件

* プロバイダー+リクエストでアイテムがネットワーク経由で自動搬送される
* モジュール挿しで挙動が変わる
* remote_orderer で遠隔要求できる
