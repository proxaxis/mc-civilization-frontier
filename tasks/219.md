# タスク: BCN Project:Red(配線/IC/モーター/blulectricity)

あなたは Minecraft MOD パックプロジェクト "Civilization Frontier: Beyond the Cataclysm" の作業エージェントです. BCN の Project:Red 系を実装します.

## 前提知識

* ワークスペース: `/ws`、Minecraft `26.3` + Fabric、Java、Fabric Mod
* BCN プロジェクト: `/ws/app` (Fabric Loom, JDK25)
  * ビルド: `JAVA_HOME=/opt/jdk25 /opt/gradle-9.8.0/bin/gradle build`
* 仕様: `/ws/docs/TECH_ITEMS.md` Project:Red 節
* 検証: testserver, RCON 25575/devpassword
* Markdown 記述ルール: `/ws/AGENTS.md`

## 既存の基盤

* redwire + 論理ゲート 10 種(206)は実績あり — PR 系はこれを拡張する形で追加
* electrotine 素材は登録済み

## タスク詳細

1. 配線系 — 色付き絶縁ワイヤー(bundle cable + 色別 insulated wire). redwire の拡張として色分離ネット
2. `ic_gate`(集積回路) — ブロック単位で複数論理を実行するコンパクトゲート. 既存 gate との違い: 内部に複数ゲートを記憶する
3. 中間素材 — シリコン, レッドシリコン, 発光/導電合金等の PR 素材群を登録+レシピ
4. モーター系 — `frame_motor`/`frame` でブロックを移動させる仕組み(PR のフレーム駆動). 最小スコープ: フレーム上のブロックを 1 方向へずらす
5. blulectricity — PR の電力系. MJ へのブリッジとして簡易実装(独自大規模はスコープ外)
6. 手ノコ — `handsaw` でブロックを 1/2, 1/4, 1/8 に分割(マイクロブロック)

優先: 素材登録 → 色付きワイヤー → ic_gate → handsaw/microblock → frame_motor

## 完了条件

* 色付きワイヤーが色別にネットワークを分離できる
* ic_gate が複数論理を 1 ブロックで処理できる
* handsaw でブロックを分割できる
