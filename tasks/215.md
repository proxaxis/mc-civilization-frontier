# タスク: BCN IC2 発電機残り(地熱/水力/風力/ソーラー/原子炉)

あなたは Minecraft MOD パックプロジェクト "Civilization Frontier: Beyond the Cataclysm" の作業エージェントです. BCN の IC2 系発電機を補完します.

## 前提知識

* ワークスペース: `/ws`、Minecraft `26.3` + Fabric、Java、Fabric Mod
* BCN プロジェクト: `/ws/app` (Fabric Loom, JDK25)
  * ビルド: `JAVA_HOME=/opt/jdk25 /opt/gradle-9.8.0/bin/gradle build`
* 仕様: `/ws/docs/TECH_ITEMS.md` IC2 節 1 + 0 章の換算表(火力4, 地熱8, 水力0.1, 風力0-2, ソーラー0.4, 原子炉2 MJ/t)
* 検証: testserver, RCON 25575/devpassword
* Markdown 記述ルール: `/ws/AGENTS.md`

## 既存の基盤

* MJ 基盤 + EngineKind 拡張方針(211 で redstone/creative 追加予定)
* EFP: クリーン電力はゼロか微減算、原子炉事故は大量加算(EFP 連携口は確立済み)

## タスク詳細

1. `generator_geothermal`(地熱) — 溶岩を消費して 8 MJ/t. 溶岩バケツ/防水パイプ受入
2. `generator_water`(水力) — 水流の有無で最大 0.1 MJ/t. 周囲の水流ブロック数で出力変化
3. `generator_wind`(風力) — 高さ・天候で 0-2 MJ/t. 高いほど強い
4. `generator_solar`(ソーラー) — 昼間のみ 0.4 MJ/t. 天候で減衰
5. `reactor`(原子炉) — ウラン燃料で 2 MJ/t だが燃料切れ・過熱でメルトダウン(爆発+周辺破壊+EFP 大量加算). ウランインゴットを燃料スロットへ
6. 各機械に燃料/環境条件 UI は不要(インベントリ+自動判定のみ)

## 完了条件

* 各発電機が条件に応じた MJ を生成する
* 原子炉が過熱でメルトダウンし EFP を大量加算する
* クリーン電力は EFP ゼロか微減算を確認
