# タスク: BCN エネルギー基盤 MJ (生成・伝送・消費 API とケーブル)

あなたは Minecraft MOD パックプロジェクト "Civilization Frontier: Beyond the Cataclysm" の作業エージェントです. 自作産業 MOD "Build Craft Neo" (BCN) のエネルギー基盤を実装します.

## 前提知識

* ワークスペース: `/ws`、Minecraft `26.3` + Fabric、Java、Fabric Mod
* BCN プロジェクト: `/ws/app` (Fabric Loom, JDK25)
  * ビルド: `JAVA_HOME=/opt/jdk25 /opt/gradle-9.8.0/bin/gradle build`
  * 成果物: `/ws/app/build/libs/bcn-0.1.0.jar` → `/ws/resources/mods/` へ配置
  * クライアントコードは `src/client/java` (splitEnvironmentSourceSets)
* 仕様正本: `/ws/resources/{buildcraft,industrialcraft,projectred,logisticspipes}/ITEMS.md`
* 実装方針: `/ws/docs/TECH_ITEMS.md` (決定事項全収録)
* 検証: testserver (コンテナ `mc_civilization_frontier_testserver`, RCON 25575/devpassword)
* Markdown 記述ルール: `/ws/AGENTS.md` (太字・中黒・句点・鉤括弧の禁止)

## 確定済みの設計 (TECH_ITEMS.md 参照)

* エネルギーは MJ に統一. 換算: `1 EU = 0.4 MJ = 4 RF`, `1 MJ = 10 RF`
* 動力伝送はケーブルのみ (BC 伝導パイプ不採用)
* MJ-P (パケット圧) ランク: `2 / 13 / 51 / 205 / 819` MJ/t
* 変圧器・蓄電器が MJ-P に連動, 損失率は IC2 源流値を流用
* EFP: 稼働時に mod 側から `cfb_efp` スコアボードへ直接書き込む連携口を API として露出

## 既存の基盤 (流用可)

* `BcnItemGroup` — bcn 名前空間全アイテムを自動収集するクリエイティブタブ
* `BcnEngineBlock` — EnumProperty facing/active の IC2 風ブロック
* `BcnPipeBlock` — 3 状態 multipart 接続(NONE/PIPE/BLOCK)の実績あり
* 登録→blockstate→モデル→テクスチャ→items.json→lang の配線は確立済み

## タスク詳細

1. MJ エネルギー API
   * 生成者(producer)/消費者(consumer)/伝送(transmitter)の抽象
   * BlockEntity ベースの MJ 残量・送受インターフェース
2. MJ-P ランクと変圧・蓄電
   * 5 段階の MJ-P. 変圧器ブロックでランク変換, 蓄電器で一時保持
   * ケーブル損失は IC2 源流値
3. ケーブルブロック
   * `BcnPipeBlock` の multipart を流用した 6 方向接続ケーブル
   * 近傍の producer/consumer を認識して MJ を送る
4. EFP 連携口
   * 稼働中 producer が `cfb_efp` に加算する API を露出

## 完了条件

* MJ が生成→ケーブル伝送→消費の往復で動く(検証用の簡易発電機+消費機で実測)
* MJ-P ランク・変圧・蓄電が機能する
* EFP 加算 API が呼べる
