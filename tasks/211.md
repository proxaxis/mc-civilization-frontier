# タスク: BCN 残りエンジン(redstone/creative)

あなたは Minecraft MOD パックプロジェクト "Civilization Frontier: Beyond the Cataclysm" の作業エージェントです. BCN のエンジン tier を補完します.

## 前提知識

* ワークスペース: `/ws`、Minecraft `26.3` + Fabric、Java、Fabric Mod
* BCN プロジェクト: `/ws/app` (Fabric Loom, JDK25)
  * ビルド: `JAVA_HOME=/opt/jdk25 /opt/gradle-9.8.0/bin/gradle build`
* 仕様: `/ws/docs/TECH_ITEMS.md` BuildCraft 節 2、発電量換算表(木エンジンは微弱発電 tier)
* 検証: testserver, RCON 25575/devpassword
* Markdown 記述ルール: `/ws/AGENTS.md`

## 既存の基盤

* `BcnEngineBlock` + `EngineKind` — STONE/COMBUSTION の実績あり. kind 拡張で tier 追加可
* `EngineBlockEntity` — 燃料消費→MJ 生成→ケーブル送出の実装済み
* エンジンは立方体+前面インジケータ+active 切替のモデル方針確立済み

## タスク詳細

1. `engine_redstone`(木エンジン)
   * 燃料不要、レッドストーン信号で超低圧 MJ 継続生成(BC の redstone engine 相当: ~0.05-0.5 MJ/t の微弱発電)
   * 燃料スロットを持たず、redstone 入力のみで active
   * レシピ: ガラス1+木材3+木歯車2+ピストン1(タスク 210 の歯車に依存)
2. `engine_creative`
   * 無限発電のクリエイティブ専用. クラフト不可、最高圧帯の大出力
3. EngineKind 拡張
   * kind ごとの燃料受付・発電量・MJ-P ランクをテーブル化して拡張可能に
4. 歯車を使う既存エンジンへのレシピ追加(210 完了前提、無ければ仮素材で可)

## 完了条件

* redstone エンジンが信号 ON で微弱 MJ を継続生成
* creative エンジンがクリエイティブタブから取得・高出力を確認
* kind 拡張で tier を増やせる構造になっている
