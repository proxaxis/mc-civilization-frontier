# 暗殺者 - Assassin の詳細

> 見えぬ刃、届かぬ声. 音もなく背後に立ち、全てを終わらせる.

影に潜んで敵の死角へ回り込み、致命的な一撃を叩き込む近接奇襲アタッカーです. 静寂と速度で獲物を屠る、闇の仕事人です.

## 1. 特徴

移動速度とクリティカル発生率が高く、背後からの一撃の破壊力は全職業随一. ただし紙装甲のため、正面からの殴り合いや集団戦は苦手. 敵を孤立させて落とす、ゲリラ戦の達人.

## 2. パッシブスキル

この職業に特有の、常時発動する能力です. 満腹度などのコストはありません. 経験値を使用して、能力を強化することができます. 獲得済みのパッシブスキルは死亡しても消えません.

> ⚠️スキル習得はこまめに<br/>
> 習得済みのパッシブスキルは死亡しても引き継がれますが、スキル交換のための経験値は消えます.

### 2.1. 影の歩法 - Shadow Step

影に紛れる軽やかな歩法が、機動力を引き上げる.

* Lv1: 移動速度 +3% / 100xp
* Lv2: +6% / 200xp
* Lv3: +9% / 400xp
* Lv4: +12% / 700xp
* Lv5: +15% / 1100xp

### 2.2. 急所の目 - Vital Eye

敵の急所を見抜く観察眼が、一撃の切れ味を増す.

* Lv1: クリティカル発生率 +2% / 100xp
* Lv2: +4% / 200xp
* Lv3: +6% / 400xp
* Lv4: +8% / 700xp
* Lv5: +10% / 1100xp

### 2.3. 暗殺の間合い - Assassin's Measure

敵の背後からの攻撃精度が上がる.

* Lv1: 背後攻撃力 +4% / 100xp
* Lv2: +8% / 200xp
* Lv3: +12% / 400xp
* Lv4: +16% / 700xp
* Lv5: +20% / 1100xp

### 2.4. 沈黙の殺気 - Silent Killing Aura

殺気を絞った気配で、敵の探知から免れやすくなる.

* Lv1: 敵探知半径 -4% / 100xp
* Lv2: -8% / 200xp
* Lv3: -12% / 400xp
* Lv4: -16% / 700xp
* Lv5: -20% / 1100xp

### 2.5. 軽業の体 - Acrobatic Body

鍛錬された体術で、落下と移動の精度が上がる.

* Lv1: 落下ダメージ -6% / 100xp
* Lv2: -12% / 200xp
* Lv3: -18% / 400xp
* Lv4: -24% / 700xp
* Lv5: -30% / 1100xp

## 3. アクティブスキル

この職業に特有の、満腹度や素材を消費して発動できる能力です. 各スキルの使用にはクールダウンタイムがあります. 使用するアクティブスキルによって、必要な素材は変わってきます.

凡例: ⬆️バフ / ⬇️デバフ / ↔️効果時間 / 🔄クールダウン / 🍖満腹度 / ⚡隠し満腹度 / 💎素材

### 3.1. 煙幕 - Smoke Veil

煙幕を展開して自分と味方の姿を隠す.

* ⬆️範囲味方をステルス化 / ↔️6秒 / 🔄40秒
* 🍖満腹度4 / ⚡8 / 💎煙幕玉

### 3.2. 影縫い - Shadow Strike

標的の背後へ瞬時に回り込み、毒と出血を付与する奇襲技.

* ⬇️毒+出血付与 / ↔️5秒 / 🔄30秒
* 🍖満腹度5 / ⚡10 / 💎短剣装備必須

### 3.3. ステルス - Stealth

姿を消して敵の探知から完全に姿を隠す.

* ⬆️完全透明化 / ↔️8秒 / 🔄60秒
* 🍖満腹度5 / ⚡12

### 3.4. 瞬刃 - Flash Blade

一瞬の踏み込みで敵の間合いへ斬り込む.

* ⬇️接近+単体斬撃 / 🔄15秒
* 🍖満腹度3 / ⚡6

### 3.5. 影走り - Shadow Dash

短距離を疾駆する機動技.

* ⬆️前方へ高速ダッシュ / 🔄12秒
* 🍖満腹度3 / ⚡5

### 3.6. 致命打 - Deathblow

クリティカルを必中させる必殺の一撃.

* ⬇️単体大ダメージ(クリティカル確定) / 🔄50秒
* 🍖満腹度6 / ⚡12 / 💎短剣装備必須

### 3.7. 麻痺針 - Paralytic Needle

麻痺性の針を投げ、対象の動きを封じる.

* ⬇️対象を麻痺(行動不能) / ↔️4秒 / 🔄35秒
* 🍖満腹度4 / ⚡8 / 💎麻痺針1

### 3.8. 残像 - Afterimage

移動中に残像を残し、敵の攻撃を惑わす.

* ⬆️敵の命中率低下 / ↔️8秒 / 🔄30秒
* 🍖満腹度4 / ⚡8

### 3.9. 闇遁 - Vanish

即座に姿を消して戦線離脱する.

* ⬆️即時透明化+移動 / ↔️3秒 / 🔄70秒
* 🍖満腹度5 / ⚡12

### 3.10. 影分身 - Shadow Clone

分身を出現させ、敵を攪乱する.

* ⬆️分身召喚(ダメージ分散) / ↔️10秒 / 🔄80秒
* 🍖満腹度7 / ⚡15

### 3.11. 断脚刃 - Hamstring

対象の脚部を斬り、移動速度を奪う.

* ⬇️移動速度 -40% / ↔️6秒 / 🔄20秒
* 🍖満腹度3 / ⚡6

### 3.12. 挑発の影 - Shadow Taunt

影で敵を誘い、自分から目標を逸らさせる.

* ⬇️対象のターゲットを攪乱 / ↔️8秒 / 🔄45秒
* 🍖満腹度4 / ⚡8

### 3.13. 深淵の呼吸 - Abyssal Breath

深い集中で次の一撃の威力を極限まで高める.

* ⬆️次回攻撃力 +50% / ↔️5秒 / 🔄40秒
* 🍖満腹度5 / ⚡10

### 3.14. 血痕の追跡 - Blood Trail

直近にダメージを与えた敵を強調表示し、追跡を助ける.

* ⬆️対象をマーキング / ↔️15秒 / 🔄30秒
* 🍖満腹度2 / ⚡4

### 3.15. 影葬 - Shadow Burial

完全な影に包まれ、標的を一撃で葬る最終奥義.

* ⬇️単体超特大ダメージ / 🔄180秒
* 🍖満腹度10 / ⚡20 / 💎伝説武器装備必須
