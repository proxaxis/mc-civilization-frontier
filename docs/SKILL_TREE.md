# スキルツリー設計 - Skill Tree Design

Pufferfish's Skills で実装する 4 職業分のツリー構造の設計図です. 1 職業 = 1 カテゴリとし、計 40〜45 ノード(パッシブ 25 + アクティブアンロック 15 + ゲート数個)を配置します.

## 1. 全体構造

* カテゴリ: `guardian` / `assassin` / `mage` / `paladin` の 4 系統. 職業選択後は自職業カテゴリのみ進行可能(排他ロックはタスク 103 で実装)
* パッシブスキル: 5 種をそれぞれ Lv1→Lv5 の直鎖ノードとして配置. 上位レベルは下位レベル取得が前提
* アクティブスキル: 15 種を「習得ノード」として配置. 取得しないと該当アイテムを用いても発動不可
* ゲートノード(マイルストーン): ツリーの層を区切る「階層解放」ノード. 経験値のほか、討伐実績やクエスト達成を条件にする想定(条件実装はタスク 103・104 と連携)

## 2. 階層(ティア)設計

* Tier 1(基礎層): 全パッシブの Lv1 + アクティブ #1〜5. 序盤で到達可能
* Tier 2(中堅層): パッシブ Lv2〜3 + アクティブ #6〜10. Tier 1 内の 2 スキル到達が前提
* Tier 3(熟練層): パッシブ Lv4 + アクティブ #11〜13. 中ボス攻略相当の実績ゲート
* Tier 4(奥義層): パッシブ Lv5 + アクティブ #14〜15. 上級ボス討伐またはクエスト達成ゲート

## 3. ノード配置と前提関係

### 3.1. Guardian(守護者)

* パッシブ列: 鋼の肉体(体力) / 重装甲適性(防御) / 不動の足場(ノックバック耐性) / 巨盾の心得(盾軽減) / 挑発の威圧(探知誘導)
* アクティブ配置:
  * Tier 1: 鉄壁の構え(巨盾 Lv1)、盾突撃(不動 Lv1)、楯の乱打(重装甲 Lv1)、守護の咆哮(挑発 Lv1)、鉄の抵抗(鋼 Lv1)
  * Tier 2: 城塞の号令(重装甲 Lv2)、忍耐の壁(不動 Lv2)、覆い隠す盾(巨盾 Lv2)、肉壁の咆哮(鋼 Lv2)、起死回生(鋼 Lv3)
  * Tier 3: 地震槌(重装甲 Lv4)、防戦結界(挑発 Lv3)、不屈の誓い(鋼 Lv4)
  * Tier 4: 聖盾の加護(挑発 Lv5)、断固たる防壁(巨盾 Lv5)

### 3.2. Assassin(暗殺者)

* パッシブ列: 影の歩法(移動) / 急所の目(クリ率) / 暗殺の間合い(背後攻撃) / 沈沈黙の殺気(探知低下) / 軽業の体(落下耐性)
* アクティブ配置:
  * Tier 1: 瞬刃(急所 Lv1)、影走り(影の歩法 Lv1)、断脚刃(暗殺 Lv1)、血痕の追跡(沈黙 Lv1)、残像(軽業 Lv1)
  * Tier 2: 煙幕(沈黙 Lv2)、影縫い(暗殺 Lv2)、麻痺針(急所 Lv2)、深淵の呼吸(急所 Lv3)、挑発の影(沈黙 Lv3)
  * Tier 3: ステルス(沈黙 Lv4)、致命打(暗殺 Lv4)、闇遁(影の歩法 Lv4)
  * Tier 4: 影分身(軽業 Lv5)、影葬(暗殺 Lv5)

### 3.3. Mage(魔道士)

* パッシブ列: 深き魔力(隠し満腹度上限) / 魔力循環(術コスト軽減) / 術式強化(威力) / 詠唱熟達(CD) / 属性適性(属性威力)
* アクティブ配置:
  * Tier 1: 火炎弾(属性 Lv1)、氷結弾(属性 Lv1 別枝)、瞬間移動(深き魔力 Lv1)、術式保存(詠唱 Lv1)、魔力障壁(魔力循環 Lv1)
  * Tier 2: 範囲火炎(術式 Lv2)、氷結領域(属性 Lv2)、魔力鮮明(術式 Lv2)、魔道加速(詠唱 Lv2)、雷鎖(属性 Lv3)
  * Tier 3: 雷撃弾(属性 Lv4)、属性同調(属性適性 Lv4)、重力操作(深き魔力 Lv4)
  * Tier 4: 終末術式(術式強化 Lv5 + 属性適性 Lv5)

### 3.4. Paladin(聖職者)

* パッシブ列: 聖なる結界(受回復増) / 信仰の耐性(状態異常耐性) / 慈悲の供給(満腹度緩和) / 回復術式熟達(回復量) / 清らかな息吹(自然回復)
* アクティブ配置:
  * Tier 1: 迅速回復(回復熟達 Lv1)、即時回復(聖なる結界 Lv1)、浄化(信仰 Lv1)、鼓舞の祈祷(慈悲 Lv1)、聖別(回復熟達 Lv1 別枝)
  * Tier 2: 祝福(慈悲 Lv2)、守護光(信仰 Lv2)、再生の誓い(聖なる結界 Lv2)、力の賛歌(慈悲 Lv3)、苦痛の代償(信仰 Lv3)
  * Tier 3: 治癒の輪(回復熟達 Lv4)、信仰の爆発(回復熟達 Lv3 別枝)、聖域の展開(清らかな息吹 Lv4)
  * Tier 4: 魂の安寧(聖なる結界 Lv5)、大聖域(回復術式熟達 Lv5 + 清らかな息吹 Lv5)

## 4. コストと進行速度

* パッシブ xp コスト: Lv1:100 / Lv2:200 / Lv3:400 / Lv4:700 / Lv5:1100(仮). 1 職業コンプで約 12,500xp
* アクティブアンロック: 各 300xp(仮)、奥義(#15)のみ 1000xp(仮)
* ゲートノード: Tier 2→3 は中ボス討伐実績、Tier 3→4 は上級ボスまたはクエスト達成を条件想定

## 5. 実装メモ

* Pufferfish's Skills の datapack JSON で `category`(職業)/`skill`(ノード)/`connection`(前提辺)/`reward`(属性・能力)を定義する形に対応
* 本設計図の数値・親子関係はタスク 103 実装時に JOB_*.md と照合して最終調整する
