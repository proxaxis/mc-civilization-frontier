# 聖職者 - Paladin の詳細

> 光は縫い止め、加護は盾. 倒れゆく者の傍らに、私は立つ.

聖なる加護によって味方の傷を癒やし、戦況を有利にコントロールするヒーラー兼バッファーです. 死地で倒れゆく者を繋ぎ止める、聖なる母の化身です.

## 1. 特徴

回復と強化でパーティの持続力を支える支援職. 火力と単体撃破力は低いが、チームの生存率に直結する最重要の補助. 満腹度の管理と回復タイミングの読み合いが、パーティの崩壊を防ぐカギ.

## 2. パッシブスキル

この職業に特有の、常時発動する能力です. 満腹度などのコストはありません. 経験値を使用して、能力を強化することができます. 獲得済みのパッシブスキルは死亡しても消えません.

> ⚠️スキル習得はこまめに<br/>
> 習得済みのパッシブスキルは死亡しても引き継がれますが、スキル交換のための経験値は消えます.

### 2.1. 聖なる結界 - Holy Barrier

聖別の力が、味方の受ける回復効果を増幅する.

* Lv1: 受回復効果 +4% / 100xp
* Lv2: +8% / 200xp
* Lv3: +12% / 400xp
* Lv4: +16% / 700xp
* Lv5: +20% / 1100xp

### 2.2. 信仰の耐性 - Faith Resilience

信仰が、状態異常への抵抗力を高める.

* Lv1: 状態異常耐性 +5% / 100xp
* Lv2: +10% / 200xp
* Lv3: +15% / 400xp
* Lv4: +20% / 700xp
* Lv5: +25% / 1100xp

### 2.3. 慈悲の供給 - Merciful Supply

味方の満腹度の消耗を緩和する祝福.

* Lv1: 満腹度消耗 -3% / 100xp
* Lv2: -6% / 200xp
* Lv3: -9% / 400xp
* Lv4: -12% / 700xp
* Lv5: -15% / 1100xp

### 2.4. 回復術式熟達 - Healing Mastery

回復術式の扱いに習熟し、効果量が増す.

* Lv1: 回復量 +5% / 100xp
* Lv2: +10% / 200xp
* Lv3: +15% / 400xp
* Lv4: +20% / 700xp
* Lv5: +25% / 1100xp

### 2.5. 清らかな息吹 - Pure Breath

周囲の味方の体力自然回復を緩やかに助ける.

* Lv1: 範囲味方の自然回復 +2%/s / 100xp
* Lv2: +4%/s / 200xp
* Lv3: +6%/s / 400xp
* Lv4: +8%/s / 700xp
* Lv5: +10%/s / 1100xp

## 3. アクティブスキル

この職業に特有の、満腹度や素材を消費して発動できる能力です. 各スキルの使用にはクールダウンタイムがあります. 使用するアクティブスキルによって、必要な素材は変わってきます.

凡例: ⬆️バフ / ⬇️デバフ / ↔️効果時間 / 🔄クールダウン / 🍖満腹度 / ⚡隠し満腹度 / 💎素材

### 3.1. 即時回復 - Heal

味方を即座に回復する聖別術式.

* ⬆️単体または範囲の即時体力回復 / 🔄15秒
* 🍖満腹度3 / ⚡6 / 💎聖印または術式巻物

### 3.2. 祝福 - Blessing

味方の攻撃力と防御力を同時に引き上げる加護術式.

* ⬆️攻撃・防御力 +20% / ↔️20秒 / 🔄60秒
* 🍖満腹度5 / ⚡10

### 3.3. 聖域の展開 - Sanctuary

範囲内に持続回復の聖域を展開する高位術式.

* ⬆️範囲内味方に継続回復 / ↔️15秒 / 🔄90秒
* 🍖満腹度6 / ⚡12 / 💎高位術式巻物

### 3.4. 浄化 - Purify

味方のデバフ・状態異常を除去する浄化術式.

* ⬆️対象のデバフ全解除 / 🔄30秒
* 🍖満腹度4 / ⚡8

### 3.5. 迅速回復 - Quick Mend

短時間で小さく回復する応急術式.

* ⬆️対象の体力を少し回復 / 🔄8秒
* 🍖満腹度2 / ⚡4

### 3.6. 鼓舞の祈祷 - Rallying Prayer

味方の士気を高め、移動速度と攻撃速度を上げる.

* ⬆️移動・攻撃速度 +15% / ↔️12秒 / 🔄40秒
* 🍖満腹度4 / ⚡8

### 3.7. 守護光 - Ward of Light

対象を光の膜で覆い、次に受けるダメージを無効化する.

* ⬆️次回被ダメージ 1 回無効 / ↔️10秒 / 🔄45秒
* 🍖満腹度5 / ⚡10

### 3.8. 聖別 - Consecrate

範囲内のアンデッドに対し継続ダメージを与える聖域術式.

* ⬇️範囲内アンデッドに継続ダメージ / ↔️10秒 / 🔄45秒
* 🍖満腹度5 / ⚡10

### 3.9. 力の賛歌 - Hymn of Might

範囲内の味方の攻撃力を強化する祈祷.

* ⬆️範囲内味方の攻撃力 +20% / ↔️15秒 / 🔄60秒
* 🍖満腹度5 / ⚡10

### 3.10. 治癒の輪 - Circle of Healing

範囲内の全味方を一斉に回復する広域術式.

* ⬆️範囲内全味方を即時回復 / 🔄50秒
* 🍖満腹度6 / ⚡12

### 3.11. 再生の誓い - Vow of Regeneration

対象に継続回復効果を付与する.

* ⬆️対象に継続回復 / ↔️20秒 / 🔄30秒
* 🍖満腹度4 / ⚡8

### 3.12. 苦痛の代償 - Martyr's Bond

対象の受けるダメージの一部を自分が代わりに引き受ける.

* ⬆️対象の被ダメージを50%代償 / ↔️10秒 / 🔄55秒
* 🍖満腹度6 / ⚡12

### 3.13. 信仰の爆発 - Faith Eruption

聖なる力を爆発させ、周囲の敵を退ける.

* ⬇️周囲の敵に聖別ダメージ+ノックバック / 🔄35秒
* 🍖満腹度5 / ⚡10

### 3.14. 魂の安寧 - Soul Repose

倒れた味方を蘇生させる最終術式.

* ⬆️倒れた味方を復活 / 🔄120秒
* 🍖満腹度8 / ⚡16 / 💎高位術式巻物2

### 3.15. 大聖域 - Grand Sanctuary

広範囲に強力な聖域を展開し、味方を総回復・強化する究極術式.

* ⬆️広域継続回復+防御強化 / ↔️20秒 / 🔄180秒
* 🍖満腹度10 / ⚡22 / 💎高位術式巻物3
