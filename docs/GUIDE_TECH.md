## 1. エネルギー

本 MOD では、`Minecraft Joules`、通称 `MJ` と呼ばれるエネルギー概念を導入します. 旧作 MOD では、MJ、EU、LP 等がエネルギー単位として存在しましたが、本作では、`MJ` に統一します. 基本的には IC2 の EU の規模感に追従します. つまり、IC2 EU = 本作 MJ です.

### 1.1. 電圧について

`MJ` は、パケットの塊として送電され、パケットサイズで電圧ランクが決まります. ケーブルには許容パケット圧があり、超過すると蒸発(ケーブル消失)します. 損失はパケット1個につき 1 ブロックあたりの固定量を減衰させる方式です. パケットを大きくまとめた方が損失は少ないということになり、高圧送電の優位性が保たれます. 1パケットあたりの容量は `MJ/p` で表します. 電圧のレベルは以下の通りです:

* 超低圧: 5 MJ/p
* 低圧: 32 MJ/p
* 中圧: 128 MJ/p
* 高圧: 512 MJ/p
* 超高圧: 2048 MJ/p

損失値については、各電線の詳細を参照してください.

## 2. 環境負荷指数、EFP について

EFP は重工業稼働で世界全体に蓄積する汚染指数. `cfb_efp` スコアボードで datapack 側が管理している. 

* 火力/内燃機関の連続稼働は、稼働時間比例. tick 単位でスコアボード加算.
* クァーリー採掘は、掘削ブロック数比例. 土地維持費との併罰. 掘削範囲登録で二重課徴防止.
* 原子炉とその爆発事故は、事故規模比例. メルトダウン時に大量加算する.
* リファイナリー精製は、バケツ単位で、少量継続加算.
* 油田の汲み上げは、源泉枯渇で加算.
* 植林やグリーン電力稼働で減算する. ソーラー/風力/水力は EFP ゼロ.

実装方式: BCN (Java) 側から `cfb_efp` スコアボードを直接更新

### 2.1. Pollution of the Realms (AdPother) との役割分担

導入済みの AdPother は「物理的汚染ブロック」(局所に漂う汚染物質, エンティティ影響, 換気)を担うMODで、EFP の「世界全体の累積指数→災害トリガー」とは別レイヤー. 併用を推奨.

- 排出源登録: BCN のエンジン, 各種炉, リファイナリー, クァーリー, 核施設を AdPother の設定 JSON で emitter 登録 → 視覚的な汚染と実害がコード無しで付く
- EFP 指数: `cfb_efp` スコアボードをグローバル指標として維持 (災害トリガーは datapack 実装済み)
- 同期: PotR jar を `modImplementation` に加えて汚染量 API を読み取り、`cfb_efp` に反映/
