# 守護者 - Guardian の詳細

> 汝の盾となろう. 汝の壁となろう. 一歩も退かぬ誓いとともに.

最前線で巨大な盾を構え、あらゆる攻撃を引き受けて味方を守り抜くタンクです. 戦線の崩壊を許さない鋼の守護者として、パーティの生命線を担います.

## 1. 特徴

体力と防御力、ノックバック耐性が群を抜いて高く、正面からの殴り合いに絶対の強さを誇る. 反面、機動力と攻撃手数は低く、単独での撃破速度は他職業に劣る. 敵の釣り出しと味方の陣地確保を同時にこなす、パーティ戦の要.

## 2. パッシブスキル

この職業に特有の、常時発動する能力です. 満腹度などのコストはありません. 経験値を使用して、能力を強化することができます. 獲得済みのパッシブスキルは死亡しても消えません.

> ⚠️スキル習得はこまめに<br/>
> 習得済みのパッシブスキルは死亡しても引き継がれますが、スキル交換のための経験値は消えます.

### 2.1. 鋼の肉体 - Iron Physique

鍛え抜かれた肉体が、あらゆる衝撃を鈍らせる.

* Lv1: 最大体力 +4% / 100xp
* Lv2: 最大体力 +8% / 200xp
* Lv3: 最大体力 +12% / 400xp
* Lv4: 最大体力 +16% / 700xp
* Lv5: 最大体力 +20% / 1100xp

### 2.2. 重装甲適性 - Heavy Plating

重装備の扱いに長け、防御効率が上がる.

* Lv1: 防御力 +3% / 100xp
* Lv2: 防御力 +6% / 200xp
* Lv3: 防御力 +9% / 400xp
* Lv4: 防御力 +12% / 700xp
* Lv5: 防御力 +15% / 1100xp

### 2.3. 不動の足場 - Stalwart Stance

踏ん張りが利き、ノックバックに強くなる.

* Lv1: ノックバック耐性 +10% / 100xp
* Lv2: ノックバック耐性 +20% / 200xp
* Lv3: ノックバック耐性 +30% / 400xp
* Lv4: ノックバック耐性 +40% / 700xp
* Lv5: ノックバック耐性 +50% / 1100xp

### 2.4. 巨盾の心得 - Greatshield Mastery

大盾の扱いに習熟し、防御姿勢時の安定感が増す.

* Lv1: 盾構え中の受ダメージ -6% / 100xp
* Lv2: -12% / 200xp
* Lv3: -18% / 400xp
* Lv4: -24% / 700xp
* Lv5: -30% / 1100xp

### 2.5. 挑発の威圧 - Provoking Presence

周囲の敵がこの守護者を優先して狙うようになる.

* Lv1: 敵探知半径 +2m / 100xp
* Lv2: +4m / 200xp
* Lv3: +6m / 400xp
* Lv4: +8m / 700xp
* Lv5: +10m / 1100xp

## 3. アクティブスキル

この職業に特有の、満腹度や素材を消費して発動できる能力です. 各スキルの使用にはクールダウンタイムがあります. 使用するアクティブスキルによって、必要な素材は変わってきます.

凡例: ⬆️バフ / ⬇️デバフ / ↔️効果時間 / 🔄クールダウン / 🍖満腹度 / ⚡隠し満腹度 / 💎素材

### 3.1. 鉄壁の構え - Bulwark Stance

大盾を構えて被ダメージを大幅にカットする防御姿勢.

* ⬆️被ダメージ -60% / ↔️8秒 / 🔄30秒
* 🍖満腹度4 / ⚡8 / 💎盾装備必須

### 3.2. 守護の咆哮 - Guardian's Roar

咆哮して周囲の敵の注意を強制的に引きつける.

* ⬆️敵のターゲットを自身へ / ↔️10秒 / 🔄45秒
* 🍖満腹度5 / ⚡10

### 3.3. 聖盾の加護 - Aegis Ward

聖別の力で自身と味方にバリアを付与する術式.

* ⬆️ダメージ吸収バリア 20% / ↔️15秒 / 🔄60秒
* 🍖満腹度6 / ⚡12 / 💎聖印または高位巻物

### 3.4. 盾突撃 - Shield Charge

盾を構えたまま敵へ突進し、ノックバックとスタンを与える.

* ⬇️対象をノックバック+スタン / ↔️3秒 / 🔄20秒
* 🍖満腹度4 / ⚡6

### 3.5. 城塞の号令 - Bastion Call

味方の防御力を一時的に引き上げる号令.

* ⬆️範囲味方の防御力 +15% / ↔️15秒 / 🔄50秒
* 🍖満腹度5 / ⚡10

### 3.6. 忍耐の壁 - Wall of Endurance

前方に一時的な障壁を展開し、通路を封鎖する.

* ⬆️障壁展開(耐久値付き) / ↔️10秒 / 🔄40秒
* 🍖満腹度5 / ⚡8 / 💎鉄ブロック1

### 3.7. 鉄の抵抗 - Iron Resolve

一定時間、状態異常とデバフを無効化する.

* ⬆️デバフ無効 / ↔️8秒 / 🔄45秒
* 🍖満腹度4 / ⚡8

### 3.8. 楯の乱打 - Shield Barrage

大盾で連続殴打し、面前の敵を押し退ける.

* ⬇️面前の敵に連続打撃+ノックバック / 🔄15秒
* 🍖満腹度3 / ⚡5

### 3.9. 不屈の誓い - Vow of Indomitability

瀕死状態から一度だけ持ち直す復帰技.

* ⬆️致死ダメージを1度だけ耐える / ↔️1回 / 🔄120秒
* 🍖満腹度8 / ⚡15

### 3.10. 覆い隠す盾 - Covering Shield

背後の味方を盾で覆い、味方への攻撃を肩代わりする.

* ⬆️背後の味方の被ダメージを50%代償 / ↔️8秒 / 🔄35秒
* 🍖満腹度5 / ⚡10

### 3.11. 地震槌 - Seismic Slam

メイスを地面に叩きつけ、周囲に衝撃波を発生させる.

* ⬇️周囲の敵にダメージ+鈍足 / ↔️5秒 / 🔄25秒
* 🍖満腹度4 / ⚡7 / 💎メイス装備必須

### 3.12. 防戦結界 - Defensive Field

周囲に防戦フィールドを展開し、範囲内の味方の被ダメージを軽減する.

* ⬆️範囲内味方の被ダメージ -15% / ↔️12秒 / 🔄60秒
* 🍖満腹度6 / ⚡12

### 3.13. 肉壁の咆哮 - Flesh Wall Roar

咆哮で自身を強化し、より固い壁となる.

* ⬆️自身の防御力 +25% / ↔️10秒 / 🔄50秒
* 🍖満腹度5 / ⚡10

### 3.14. 起死回生 - Second Wind

深い呼吸で体力を緩やかに回復する.

* ⬆️体力を徐々に回復 / ↔️10秒 / 🔄70秒
* 🍖満腹度6 / ⚡10

### 3.15. 断固たる防壁 - Unbreakable Bulwark

全てを賭した究極の防御姿勢. 効果中は移動不可だがほぼ無敵となる.

* ⬆️被ダメージ -90%、移動不可 / ↔️6秒 / 🔄150秒
* 🍖満腹度10 / ⚡20
