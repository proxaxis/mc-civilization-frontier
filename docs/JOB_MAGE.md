# 魔道士 - Mage の詳細

> 言葉は力、旋律は破壊. 一度紡げば、戦場は焼き尽くされる.

後方から多彩な術式を紡ぎ出し、広範囲の敵を一網打尽にする遠距離魔法アタッカーです. 属性を自在に操る、古代魔導の継承者です.

## 1. 特徴

火炎・凍結・雷撃の属性術式で、範囲制圧力は全職業随一. 反面、被弾時の耐久と近接戦に弱く、位置取りと詠唱間の管理が生死を分ける. 火力は高いが繊細な砲台.

## 2. パッシブスキル

この職業に特有の、常時発動する能力です. 満腹度などのコストはありません. 経験値を使用して、能力を強化することができます. 獲得済みのパッシブスキルは死亡しても消えません.

> ⚠️スキル習得はこまめに<br/>
> 習得済みのパッシブスキルは死亡しても引き継がれますが、スキル交換のための経験値は消えます.

### 2.1. 深き魔力 - Deep Mana

研ぎ澄まされた魔力回路が、術式を支える隠し満腹度の容量を拡大する.

* Lv1: 隠し満腹度の最大値 +6% / 100xp
* Lv2: +12% / 200xp
* Lv3: +18% / 400xp
* Lv4: +24% / 700xp
* Lv5: +30% / 1100xp

### 2.2. 魔力循環 - Mana Circulation

体内の魔力循環が、術コストとなる満腹度の消耗を緩和する.

* Lv1: 術の満腹度消費 -5% / 100xp
* Lv2: -10% / 200xp
* Lv3: -15% / 400xp
* Lv4: -20% / 700xp
* Lv5: -25% / 1100xp

### 2.3. 術式強化 - Spell Amplification

組み込まれた術式回路が、魔法の威力を引き上げる.

* Lv1: 魔法攻撃力 +4% / 100xp
* Lv2: +8% / 200xp
* Lv3: +12% / 400xp
* Lv4: +16% / 700xp
* Lv5: +20% / 1100xp

### 2.4. 詠唱熟達 - Chanting Mastery

詠唱技術の習熟で、術式の回転効率が上がる.

* Lv1: 術のクールダウン -3% / 100xp
* Lv2: -6% / 200xp
* Lv3: -9% / 400xp
* Lv4: -12% / 700xp
* Lv5: -15% / 1100xp

### 2.5. 属性適性 - Elemental Affinity

属性術式との親和性が高まる.

* Lv1: 属性術式の威力 +4% / 100xp
* Lv2: +8% / 200xp
* Lv3: +12% / 400xp
* Lv4: +16% / 700xp
* Lv5: +20% / 1100xp

## 3. アクティブスキル

この職業に特有の、満腹度や素材を消費して発動できる能力です. 各スキルの使用にはクールダウンタイムがあります. 使用するアクティブスキルによって、必要な素材は変わってきます.

凡例: ⬆️バフ / ⬇️デバフ / ↔️効果時間 / 🔄クールダウン / 🍖満腹度 / ⚡隠し満腹度 / 💎素材

### 3.1. 属性爆発 - Elemental Burst

杖から属性爆発を放ち、広範囲の敵を焼き払う.

* ⬇️火炎または雷撃の範囲爆発 / 🔄25秒
* 🍖満腹度6 / ⚡12 / 💎杖または術式巻物

### 3.2. 魔道加速 - Arcane Surge

一時的に詠唱速度を跳ね上げ、術式を連射する自己強化.

* ⬆️詠唱速度 +50% / ↔️10秒 / 🔄50秒
* 🍖満腹度6 / ⚡12

### 3.3. 瞬間移動 - Blink

短距離を瞬時にワープする移動術式.

* ⬆️前方へ瞬間移動 / 🔄20秒
* 🍖満腹度4 / ⚡8

### 3.4. 火炎弾 - Firebolt

火炎の投射体を放つ基本攻撃術式.

* ⬇️単体火炎ダメージ+火傷 / ↔️3秒 / 🔄8秒
* 🍖満腹度2 / ⚡4 / 💎火炎ルーン1

### 3.5. 氷結弾 - Frostbolt

氷の投射体で対象を遅滞させる攻撃術式.

* ⬇️単体凍結ダメージ+鈍足 / ↔️4秒 / 🔄10秒
* 🍖満腹度3 / ⚡5 / 💎氷結ルーン1

### 3.6. 雷撃弾 - Shockbolt

稲妻を放ち、対象を痺れさせる攻撃術式.

* ⬇️単体雷撃ダメージ+スタン / ↔️2秒 / 🔄12秒
* 🍖満腹度3 / ⚡6 / 💎雷撃ルーン1

### 3.7. 魔力障壁 - Mana Shield

魔力で障壁を展開し、被ダメージを隠し満腹度で相殺する.

* ⬆️被ダメージの30%を隠し満腹度で相殺 / ↔️10秒 / 🔄45秒
* 🍖満腹度4 / ⚡8

### 3.8. 範囲火炎 - Inferno Wave

前方に火炎の波を放ち、複数の敵を焼く.

* ⬇️扇状範囲火炎ダメージ / 🔄20秒
* 🍖満腹度4 / ⚡8 / 💎火炎ルーン2

### 3.9. 氷結領域 - Frost Domain

周囲に氷の領域を展開し、敵の動きを封じる.

* ⬇️範囲内の敵に鈍足+継続凍結 / ↔️8秒 / 🔄40秒
* 🍖満腹度5 / ⚡10 / 💎氷結ルーン2

### 3.10. 雷鎖 - Chain Lightning

敵を数珠つなぎに雷撃で貫く範囲攻撃.

* ⬇️最大5体に連鎖雷撃 / 🔄30秒
* 🍖満腹度5 / ⚡10 / 💎雷撃ルーン2

### 3.11. 魔力鮮明 - Mana Flare

蓄積した魔力を放出し、範囲内の敵を押し飛ばす.

* ⬇️周囲の敵に衝撃+ノックバック / 🔄25秒
* 🍖満腹度4 / ⚡8

### 3.12. 術式保存 - Spell Cache

次の術の消費を一時的にゼロにする蓄積術.

* ⬆️次回術コスト0 / ↔️10秒 / 🔄60秒
* 🍖満腹度5 / ⚡10

### 3.13. 属性同調 - Elemental Attunement

属性への適合を強化し、術威力を底上げする.

* ⬆️属性術式威力 +30% / ↔️15秒 / 🔄70秒
* 🍖満腹度6 / ⚡12

### 3.14. 重力操作 - Gravity Well

地点に重力場を生成し、敵を吸い寄せる制御術式.

* ⬇️範囲内の敵を吸い寄せ+移動封じ / ↔️6秒 / 🔄50秒
* 🍖満腹度6 / ⚡12 / 💎高位術式巻物

### 3.15. 終末術式 - Final Incantation

全魔力を解放する最終術式. 広範囲を焼き尽くす.

* ⬇️超広範囲属性大爆発 / 🔄200秒
* 🍖満腹度10 / ⚡25 / 💎高位術式巻物3

## 5. 装備品

* 📖クラフト

* 📖各種ダンジョンの攻略報酬
