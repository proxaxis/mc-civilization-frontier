# 第 2 章 - ⚙️産業

## 説明

手つかずの自然を切り倒し, 失われた文明の技術を呼び醒ませ. エンジンを組み上げて基本動力を生み出し, 自動採掘機や精錬ラインを稼働させて資源を掌握するのだ. ただし, 過剰な重工業化がもたらす環境負荷指数には常に目を配らねばならない. 空が黄昏に染まり, 災厄が大地を覆い尽くす前に.

## 目的

動力を生み出す基本エンジンを建造し, パイプラインによる自動精錬・搬送インフラと露天掘り機を稼働させるとともに, 環境汚染の管理体制を確立する.

## クエスト一覧

### 鼓動する機関

- id: c2_engine
- 説明: 本ワールドの機械を動かす基本動力 Minecraft Joules を生成します. 熱暴走や燃料効率に注意しながら, 安定した動力源を確保してください.
- 要件:
  - have:bcn:engine_stone x1 ※設置・稼働の検出は不可のため所持確認に代替
- 報酬:
  - coinsje:iron_coin x5
  - xp:150
  - minecraft:coal_block x4
  - bcn:cable_copper x8 ※MJ伝送はケーブルのため置換

### 物流の動脈

- id: c2_logistics
- 説明: 採掘・精錬の自動化に不可欠な配管ラインを敷設します. 物資の逆流やアイテム詰まりを起こさないよう, 適切な物流ルートを設計しましょう.
- 要件:
  - have:bcn:item_pipe x16 ※抽出パイプ・接続状態は検出不可のため所持確認に代替
- 報酬:
  - coinsje:iron_coin x5
  - xp:150
  - bcn:wrench x1
  - minecraft:chest x4

### 大地を穿つ爪

- id: c2_quarry
- 説明: 広範囲の地下資源を一挙に掘り出す科学拠点の中核設備です. 膨大な MJ 動力を消費するため, 安定した電力供給ラインを繋げてください.
- 要件:
  - have:bcn:quarry x1 ※稼働検出は不可のため所持確認に代替
  - have:bcn:landmark x3 ※範囲指定の代替として併せ持ちを要求
- 報酬:
  - coinsje:iron_coin x15
  - xp:300
  - minecraft:diamond x2
  - bcn:gear_iron x2 ※強化歯車→鉄歯車代替

### 煤煙と代償

- id: c2_efp
- 説明: 重工業の稼働によって世界に蓄積される汚染指数です. 閾値を超えると黄昏, モンスター大量発生, 拠点襲撃などの災害が発生するため, 排気管理と緑化を怠ってはなりません.
- 要件:
  - flag:efp_checked ※測定器アイテムは存在しないため /trigger cfb_efpcheck で EFP 表示+フラグを立てる方式に
- 報酬:
  - coinsje:iron_coin x10
  - xp:200
  - bcn:fertilizer x4 ※大気浄化フィルター→肥料代替
  - minecraft:oak_sapling x16 ※各種苗木を oak に統一
