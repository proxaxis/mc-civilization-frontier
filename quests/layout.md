# クエストブックの基本レイアウト

* 各章ごとに1冊のクエストブックを作成します.
* 職業選択時やリスポーン時に `クエストブック` を配ります.
* クエストブック内の `取得` を押すと、`クエストシート` がもらえます.

## クエストブック

### 1ページ
```
⚙️Civilization Frontier

―― 創世か、終焉か.
大災厄によって旧文明が崩壊した世界.
頭上には浮遊城塞、
足元には無限の迷宮が広がり、
安息の地はどこにもない.
己の職業を定め、
街道の酒場を確保し、
最初の道具を作れ.
産業を興して資源を掌握し、
失われた遺産を取り戻す戦いが今始まる.

歯車を回せ、剣を抜け!
新たな時代を築くのは君だ!
```

### 2ページ
```
⚙️クエスト本 > ブックメニュー

[章番号(2桁、ゼロ埋め)]. [章絵文字とタイトル] [取得ボタン]
```

## 各クエストシート

### 1ページ
```
第 [章番号] 章 - [章絵文字と章タイトル]

[章の説明]
```

### 2ページ
```
[章絵文字][章番号] > 目的

[章の目的]
```

### 3ページ
```
[章絵文字][章番号] > 📜クエスト

[完了済みなら☑|未完了なら☐] [節番号(2桁、0埋め)] [クエスト名]
```

### 4ページ以降
```
[章絵文字][章番号] > 📜[節番号] > [クエスト名(改行禁止、省略記号…を使う)]
>> 🪙[報酬MD] ✨[報酬経験値] 💎[報酬アイテム]
🔶[要件1]
🔶[要件2]

[申請]

[クエストの詳細説明]
```
