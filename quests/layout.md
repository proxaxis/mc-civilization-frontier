# クエストブックの基本レイアウト

* 各章ごとに1冊のクエストブックを作成します.
* 職業選択時やリスポーン時に `クエストブック` を配ります. これは子の本 `クエストシート` を配るために使用します.
* クエストブック内の `取得` を押すと、子の本 `クエストシート` がもらえます.

## クエストブック

### 1ページ

```
⚙️Civilization Frontier

創世か、終焉か ――
開拓、産業、経済、そして迫りくる強大な災厄 ―― 歯車を回せ! 剣を抜け!
新たな文明を創造するか、破滅の露と消えるか、すべてはあなたの選択と手腕に委ねられている!
```

### 2ページ
```
⚙️ > ブックメニュー

[章番号(2桁、ゼロ埋め)] >> [章絵文字][章タイトル] [取得]
```

## 各クエストシート

### 1ページ
```
📜 > [章番号(2桁、ゼロ埋め)] - [章絵文字][章タイトル]

[章の説明]
```

### 2ページ
```
📜 > [章絵文字] > 目的

[章の目的]
```

### 3ページ
```
📜 > [章絵文字] > リスト

[完了済みなら☑|未完了なら☐] [節番号(2桁、0埋め)]. [クエスト名]
```

### 5,7,9...以降
